# Imran Khan Portfolio (Next.js)
1. Copy `images/imran.png` and `images/favi.png` from your old repo into `public/` (as `imran.png` and `favi.png`).
2. `npm install` then `npm run dev` and open http://localhost:3000
3. Optional: copy `.env.example` to `.env.local` and add a GitHub token if the API rate-limits you.
4. Deploy: push to GitHub and import the repo on vercel.com.
Edit your name, bio and skills in `data/site.ts`.
